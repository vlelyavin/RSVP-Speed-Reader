Privacy Policy

Last updated: January 17, 2025

Introduction

RSVP Speed Reader ("the Extension") is a Chrome browser extension that enables users to read selected text using the Rapid Serial Visual Presentation (RSVP) technique. This privacy policy explains how the Extension handles user data.

Data Collection

The Extension does NOT collect, store, transmit, or share any user data with external servers.

The Extension operates entirely locally on your device and does not:

  • Collect personal information
  • Track your browsing activity
  • Send data to external servers
  • Use analytics or tracking services
  • Share data with third parties

Local Storage

The Extension uses Chrome's storage.local API to store the following information only on your device:

  • Reading speed preference (100-1000 WPM)
  • Font size preference (40-120px)
  • Other display settings

This data:

  • Is stored locally on your device only
  • Is NOT synced to external servers
  • Is NOT shared with anyone
  • Can be cleared at any time via Chrome's extension settings

Permissions

The Extension requests the following permissions and uses them as follows:

contextMenus

  • Purpose: Adds a "Read with RSVP" option to the right-click context menu
  • Usage: Only activates when you select text and right-click
  • Data: No data is collected from this permission

activeTab

  • Purpose: Allows reading selected text from the currently active browser tab
  • Usage: Only accesses text that you explicitly select
  • Data: Text processing happens entirely in your browser, never transmitted

storage

  • Purpose: Saves your reading preferences locally
  • Usage: Stores only your settings (speed, font size) on your device
  • Data: Settings stored locally only, never synced or transmitted

Content Scripts

The Extension injects content scripts on:

  1. All web pages - To enable the context menu reading feature
  2. X.com and Twitter.com - To add a "Speed read" option to post menus

These scripts:

  • Only run when you interact with the page (right-click or open menu)
  • Do not collect or transmit data
  • Operate entirely within your browser

X/Twitter Integration

When using the Extension on X.com or Twitter.com:

  • The Extension adds a "Speed read" menu item to post menus
  • Text is extracted locally from the page
  • No data is sent to X/Twitter or any external server
  • The Extension does not access your X/Twitter account or credentials

Third-Party Services

The Extension does not use any third-party services, analytics, or external APIs.

Updates

This Extension may be updated periodically to add features or fix bugs. Updates are delivered through the Chrome Web Store and do not change the Extension's data collection practices described in this policy.

Data Deletion

You can delete all locally stored data at any time by:

  1. Going to chrome://extensions/
  2. Finding "RSVP Speed Reader"
  3. Clicking "Remove" (this deletes all local data)

Or by manually clearing Chrome's extension storage via developer tools.

Children's Privacy

The Extension does not knowingly collect data from children under 13. Since no data is collected, this is not a concern, but we make this statement for completeness.

Changes to This Policy

If this privacy policy changes, we will update the "Last updated" date at the top of this document. Significant changes will be noted in the Extension's update notes.

Contact

For questions about this privacy policy, please contact:

  • Website: https://vlelyavin.github.io/RSVP-Speed-Reader/

Summary

In short: This Extension is designed with privacy in mind. It does not collect, store, transmit, or share any user data. All processing happens locally on your device, and all preferences are stored only on your device.
